# 0.2.2 — 2026-10-22

- 处理旧版“载入完成”但 Steam 仍启动官方启动器的入口缺口：备份并修改当前 Steam 账号的绝区零 LaunchOptions，明确运行稳定目录中的游戏选择前端。
- 增加启动项读回、前端/辅助程序哈希、目录标记和安装清单校验；旧版状态提示修复，不再仅凭 enabled 字段显示正常。
- 增加“修复启动入口”：原地升级旧版组件与路径配置，保留最初的撤回备份；失败时恢复操作前状态。
- 撤回只还原本工具写入的启动项，保留其他游戏配置和用户后续改动；VDF 编辑保留编码、BOM、注释和未触及的文本。
- 增加可导出的针对性诊断和前端启动记录，区分启动入口未执行与选卡后失败。
- 补齐 96 DPI 缩放基准，管理界面使用自动行高与滚动布局，修正字体放大后的遮挡和截断。

# 0.2.1 — 2026-10-22

- 修复 Windows .NET Framework 下找不到 String.Split(Char, StringSplitOptions) 的错误。
- 路径检查和 Steam 元数据解析显式调用 Char[] 重载。
- Mono 构建强制使用微软官方 .NET Framework 4.8 参考程序集，不再使用 Mono 实现程序集作为 API 目标。
- 新增对管理程序和嵌入前端的实际 IL 方法调用检查；确认可检出旧 0.2.0 包的两处不兼容调用。
- 保留双游戏选择、官方图片和原有安装记录兼容性。安装过旧版需撤回后重新载入。

# 0.2.0 — 2026-10-22

- 按原项目 v0.2.4 双游戏选择窗口改为“绝区零 / 崩坏：星穹铁道”。
- 加入两个独立路径、单游戏安装支持、不可用卡片禁用及选择界面预览。
- 选择结果显式传给管理员辅助程序，重新校验后启动正确的游戏 EXE。
- 配置和客户端检测支持 StarRail.exe / StarRail_Data；保留旧版 Game 字段兼容性。
- 游戏进程监护按所选游戏工作。
- 内置两款游戏的米哈游官方宣传图，附图片来源与权利说明。
- 两款游戏统一计入 Steam《绝区零》入口；升级前先撤回旧版载入。
